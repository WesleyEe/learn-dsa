# Unit 1 — Complexity Analysis, Arrays & Strings

## Steps
1. Read `concepts.md` in full first.
2. Solve the problems in `problems/` **in order** — each one has a
   docstring with the task, examples, and hints. Don't skip the "state
   time/space complexity in a comment" instruction; that habit is graded
   from day one.
3. Sanity-check your own work by running each file:
   ```bash
   python3 problems/01_max_subarray_sum.py
   ```
   If the asserts pass silently and print "All sample tests passed.", the
   visible cases pass — but that's not full coverage. I'll test edge cases
   during review.
4. When all 5 are done, tell me "review unit 1" (or paste your code) and
   I'll grade each one, fix bugs, explain the optimal approach if you
   missed it, and note anything shaky before we move to Unit 2.
